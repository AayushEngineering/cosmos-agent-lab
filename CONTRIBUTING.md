# Contributing

Contributions are welcome when they make the lab more useful, more reliable, or safer.

## Good first contributions

- Add source-linked scientific examples and replication notes.
- Improve memory retrieval and compare it against the lexical baseline.
- Add evaluation datasets with clear licenses and provenance.
- Add tests for malformed data, tool misuse, and uncertainty handling.
- Document failure cases and reproducibility gaps.

## Contribution expectations

1. Open an issue describing the problem and proposed change.
2. Keep pull requests focused and include tests for behavior changes.
3. Include an evaluation for new agent capabilities.
4. Document new permissions, external side effects, and data handling.
5. Never commit secrets, private data, or credentials.
6. Do not present speculative results as established scientific facts.

By contributing, you agree that your contributions may be distributed under the repository's MIT license.
